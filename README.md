# 🖥️ 42 Unity Piscine

---

## Projektinfos

Das Unity Piscine war ein intensiver, 7-tägiger Bootcamp-Einstieg in das Unity Game Development. Ziel des Projekts war die Entwicklung eines eigenen 3D-Spiels sowie das Erlernen fundamentaler Spielmechaniken – darunter Physik und Gravitation, Charaktersteuerung, User-Input-Processing und die Erstellung sowie Handhabung von 3D-Umgebungen.
